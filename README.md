## 📌 專案簡介

**GoWonder Travel Guide** 是一個專為自由行與自助旅行愛好者設計的旅遊指南網站。以活潑繽紛的旅遊雜誌風格，呈現精選城市特色景點、在地道地美食、自由行建議與簡易推薦行程。

全站具備：
1. **即時探索與全域智慧關聯搜尋**：支援城市名稱即時關鍵字搜尋（中英文不拘），更支援輸入景點（如「龍山寺」、「自由女神」）或在地美食（如「牛肉麵」、「太陽餅」）自動關聯推薦城市，並能依國家與熱門體驗標籤精準篩選。
2. **共用動態詳細頁面架構**：以統一規格模板動態加載目的地資料，新增城市不需重新編寫或修改畫面程式碼。
3. **直覺化全卡片點擊體驗**：卡片支援點選任意區域即可直接跳轉進入詳細探索頁，同時為愛心收藏按鈕設置事件隔離保護。
4. **無縫本機收藏庫**：採用 `LocalStorage` 保存喜歡的城市與私房景點，重新整理或關閉視窗不遺失，支援即時統計徽章與清空管理。
5. **透明嚴謹的來源與授權揭露**：100% 引用官方旅遊局或景點官網真實資訊，每張照片均載明原創作者、商用許可與真實來源，並通過自動化連線健康檢測。
6. **首頁雜誌風格簡潔排版**：首頁與頁尾各區塊固定精選 3 筆代表性內容，搭配清晰行動按鈕（CTA），兼顧資訊豐富度與排版輕快俐落。
7. **響應式全裝置支援**：完美適配桌面、平板與手機螢幕，手機版嚴格防止水平溢位。

## 🚀 快速開始 (Local Development)

### 1. 安裝相依套件

在專案目錄下執行：

```bash
npm install
```

### 2. 啟動本機開發伺服器

```bash
npm run dev
```

啟動後於瀏覽器開啟終端機顯示之網址（通常為 `http://localhost:5173/`）。

### 3. 正式建置 (Production Build)

```bash
npm run build
```

建置完成之靜態檔案將輸出至 `dist/` 資料夾。

### 4. 預覽正式建置結果

```bash
npm run preview
```

### 5. 一鍵圖片健康檢測 (Image Health Check)

```bash
npm run check:images
```
自動對全站所有景點、美食與城市封面圖片進行真實 HTTP 連線測試，確認全數 200 OK，無 403 防盜鏈阻擋或 404 死鏈。

## ➕ 如何新增城市或景點（擴充規範）

**本專案嚴格落實「資料與畫面完全分離」原則**，新增任何城市、景點或美食時，**不需更動任何 JSX 頁面**。請遵循以下收錄與收斂原則：

* **收錄數量規範**：每座目的地收錄 **3～6 個必訪景點**（大都會 5～6 個，特色小鎮 3～4 個）與 **2～6 道特色美食**。
* **首頁與頁尾簡潔原則**：首頁卡片（推薦城市、必訪景點、在地料理）與頁尾連結固定維持**精選 3 筆呈現**，搭配清晰行動按鈕導向 Explore 完整清單，保持版面輕快俐落。
* **圖片品質規範**：所有外部圖片必須具備明確商用授權，且上線前必須執行 `npm run check:images` 確認 100% 通過（HTTP 200 OK，無死鏈或防盜鏈）。

擴充時請依照以下步驟依序編輯 `src/data/` 中的檔案：

1. **`src/data/sources.js`**：加入官方旅遊網站或政府觀光局之可靠來源。
2. **`src/data/imageCredits.js`**：加入經確認具有合法公開商用使用權的圖片資訊（`usagePermission: "verified"`）。
3. **`src/data/attractions.js`**：新增景點，設定唯一的 `id`、正確的 `destinationId`，以及對應的 `imageCreditIds` 與 `sourceIds`。
4. **`src/data/food.js`**：新增美食，填寫推薦品嚐店家與價格區間。
5. **`src/data/destinations.js`**：新增城市資料，填入 `attractionIds`、`foodIds` 與三日遊規劃。

儲存後，首頁、探索頁（包括即時關聯搜尋與過濾 Pills）、詳細頁面與收藏系統皆會**自動動態加載並生效**！

## 🌐 部署至 GitHub Pages

專案已內建 `.github/workflows/deploy.yml` 自動部署設定檔：

1. 將本專案 Push 至 GitHub 儲存庫（建議倉庫名稱為 `gowonder-travel-guide` 或個人自訂名稱）。
2. 在 GitHub 儲存庫的 **Settings > Pages** 中，將 **Source** 設定為 **GitHub Actions**。
3. 未來只要將程式碼 Push 到 `main` 分支，GitHub Actions 便會自動執行依賴安裝、正式建置，並發布至 GitHub Pages！
